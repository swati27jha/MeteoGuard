Model Information & Architecture

Transparent technical documentation of MeteoGuard inference engine

AI Model Specification

Architecture: Per-station Autoencoder (72 → 16 → 72)
Input Window: 72-hour multivariate time series (Temperature, Humidity, Pressure)
Reconstruction Error: Mean Squared Error (MSE) computed against station latent manifold
Adaptive Threshold: Rolling baseline + 1.5× standard deviation

Physics Threshold Matrix

  • • Temperature: Rate of change ≤ 5.0°C / hour | Physical bounds: -10°C to +55°C
  • • Pressure: Rate of change ≤ 3.0 hPa / hour | Physical bounds: 870 hPa to 1080 hPa
  • • Humidity: Rate of change ≤ 15.0% / hour | Physical bounds: 0% to 100%

Data Source & Operational Integration Note

NOAA ISD is used as a proxy dataset for this prototype. Official IMD integration would be required for operational deployment.

Deploying MeteoGuard in operational meteorological centres requires connecting directly to IMD AWS REST telemetry endpoints. Synthetic fault injection was utilized during prototype evaluation due to lack of publicly labelled Indian AWS fault datasets.
